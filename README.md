# ML Project — Student Performance Prediction

## Team Members

* Golam Moktadi

## Problem Idea

This project explores whether student performance can be predicted using factors such as study hours, sleep hours, attendance, and snack purchases. The goal is to understand the basic machine learning workflow and identify patterns in a small student dataset.

## Current Dataset Status

The current dataset is a small sample dataset containing student information, study hours, sleep hours, attendance, snack purchases, and pass/fail results. The dataset is currently being used for initial exploration and learning purposes.

## How to Run the Notebook

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the cells from top to bottom.
3. Make sure the required Python libraries are installed.

## Results

The results are preliminary and are intended for learning and experimentation. They should not be treated as final research conclusions.
